# Peso Tracker

This project is a weight tracking application built using NiceGUI. The application allows users to track their weight progress over time, set goals, and visualize their achievement.

## Features
- Track weight entries in a CSV format
- Set weight goals
- Visualize progress on a goal

## Installation
To get started, you will need to install the required dependencies. Run the following command:

```bash
pip install -r requirements.txt
```

## Usage
To start the application, run the following command after installing the dependencies:

```bash
python app.py
```

Enjoy tracking your weight progress!
